The following is the codebook for the interviews.

| Theme | Sub-theme | Code | Description |
| :--- | :--- | :--- | :--- |
| **Perceived S&P Benefits** | | Deepfake, fraud and deception prevention | Perceptions regarding the utility of AI labels in mitigating malicious exploits, identity spoofing, and synthetic disinformation. |
| | | Authenticity proof | Perceptions regarding how AI labels assist audiences in verifying content origins and separating synthetic from real records. |
| | | Prevent proprietary data from unauthorized use | Views on labels as a protective layer to safeguard biometric data, portrait photos, or creative concepts from unconsented training/use. |
| | | Tamper detection | Perceptions on leveraging personal or user IDs to detect and mitigate malicious modifications of publicly distributed work. |
| | | Forensics | Perspectives on using platform/creator-level labels as critical tracing evidence during infringement disputes or regulatory investigation. |
| | | Data stealing and extraction prevention | Views on how AI labels increase the economic cost and friction of automated data scraping, content piracy, or model spinning. |
| | | Copyright protection | Views on the capability of labels to signal authorship and mitigate infringement, despite platform terms-of-service ambiguities. |
| **Perceived S&P Risks** | | Data leakage | Apprehensions that embedded identifiers can be exposed or cross-linked. |
| | | De-anonymization | Fears that platform-embedded labels act as trackable fingerprints that undermine creator anonymity across disconnected accounts. |
| | | False authenticity | Anxieties regarding platform enforcement of opaque automated AI detectors, uncalibrated errors, and subsequent traffic penalties. |
| **Remove AI Labels** | What | Visible AI labels | They remove visible AI marks, such as logos of companies. |
| | | Metadata | They remove the metadata embedded in the image, such as the model used. |
| | In what context | Commercial context | They remove the marks when their files are related to commercial transactions. |
| | | Academic | They remove the marks when submitting academic work or papers. |
| | | Competitive | They remove the marks in competitions. | 
| | When | Post-generation editing | They remove the marks during the editing process after the generation. |
| | | Export stage | They remove the marks when exporting the work. |
| | How | Third-party applications | They remove the marks using applications provided by other parties. | 
| | | Crafted tools | They remove the marks using their own self-made tools. |
| | Why | Manage credibility | They remove the marks to let the audience perceive them as credible, or trustworthy. | 
| | | Prevent platform deprioritization | They remove the marks to avoid being misjudged or miscredited from the platform.| 
| | | Regulation compliance | They remove the marks for complying with platform or local laws.| 
| **Retain AI Labels** | What | watermarks | They retain watermarks, especially platform-added ones. | 
| | | Metadata | They retain the metadata embedded in the file. | 
| | | Visible AI-tags | They retain the visible AI tags, such as platform logos, included in the image. | 
| | In what context | Educational sharing | They retained AI labels when sharing educational materials with others. | 
| | | Regulatory environments | They retained AI labels for regulatory usage. | 
| | | Audience communication | They retained AI labels when needing to communicate with audience, especially for transparency. | 
| | When | Final publication | They retained AI labels during the final publication process. |
| | How | Accept platform exports | Retain the watermark added by the platform. | 
| | | Restore unified mark | Replace the platform watermark with a unified mark or a self-designed one. | 
| | Why | Foster transparency | Retain watermark for transparent communication about how the work is made. |
| | | Regulatory compliance | Comply to the regulations from the platforms or specific laws. | 
| | | Minimize friction | Watermark removing is too difficult or laborious. | 
| | | Mitigate misinformation | prevent misinformation by warning users of synthetic content. | 
| **Add AI Labels** | What | Visible marks | Participants add self-made visible marks such as logos. | 
| | | Invisible marks | Participants add invisible marks such as text characters or pixel modifications. | 
| | In what context | Economic | They add labels because the content has high economic value. | 
| | | Sensitive | They add labels because the information to protect is private. | 
| | | Vulnerable to scraping | They add labels because otherwise their work maybe misused. | 
| | When | Early during drafting | They add labels when they draft the image. | 
| | | Export stage | They add labels during the final export process before the publication. | 
| | How | Embed in files | They add labels through directly embed in files. | 
| | Why | Protect intellectual property | They add labels to protect their own work's IP. | 
| | | Reduce data theft | They add labels to prevent the data from being misused. | 
| | | Privacy calculus | They think that adding labels would not compromise their identity. |
